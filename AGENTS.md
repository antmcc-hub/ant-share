# ant-share Agent Instructions

This public repository contains scrubbed, shareable agent skill drafts and notes.

Keep all content public-safe: no client or person names, internal hostnames or paths, account names, ticket IDs, or deployment details.
Remove private project context and secrets; use generic examples.

- `skills/`: shareable skill drafts.
- `docs/`: publishing rules and documentation.
- `slack/`: provenance notes formatted for sharing.
- `scripts/`: index-building and packaging helpers.
- `data/`: generated skill index.
- `dist/m365/`: packaged skill archive.
- `.agents/`, `.claude-plugin/`, `.codex-plugin/`: marketplace and plugin metadata.
- `.github/workflows/`: packaging automation.
